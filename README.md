# CS 330 Portfolio Reflection

I approach designing software by breaking a project into smaller parts and deciding how those parts will work together. This project helped me learn how to turn a reference image into a 3D scene using basic shapes, textures, and lighting. I started with the shapes and their placement, then added camera controls, textures, and lighting throughout the milestones. Working in stages helped me focus on one part at a time and make adjustments as the scene developed. I can use this same approach in future projects by planning the main features first and improving the details after the basic program works.

I approach developing programs by building and testing small sections before moving forward. While working on my 3D scene, I learned to adjust object transformations, apply textures, add lighting, and test camera movement. Iteration was a major part of the process because I had to run the program, inspect the scene, and revise parts that did not look or behave as expected. Throughout the milestones, I became more comfortable finding problems and understanding how changes in the code affected the scene. This helped me become more patient with debugging and more careful about testing each change.

Computer science can help me reach my goals by strengthening my ability to solve problems and understand how programs work. Computational graphics gave me more experience with C++, coordinates, transformations, and user interaction. These skills can help me in future coursework that involves programming, mathematics, or visual applications. Professionally, I am interested in reviewing code, finding errors, and fixing problems so programs run successfully. This project gave me practice with those skills because I had to connect what I saw on the screen to the code responsible for it.
